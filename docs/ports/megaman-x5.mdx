### Install the Mega Man X5 Recomp App
- Grab the `MegaManX5RecompUWP.appx` file.
- Open the Xbox Device Portal.
- Install the `MegaManX5RecompUWP.appx` file via the dev portal.
- Install the `Microsoft.VCLibs.x64.14.00.appx` dependency file if requested.

### Internal Storage Setup
- Start the app once to generate the `Localstate` folders for the app.
- Upload your `.BIN` and `.CUE` files into the `Localstate/Game` folder for Mega Man X5 Recomp UWP.
- Now in the app, select **Internal Storage**.
- Select your legally obtained Mega Man X5 USA `.BIN` file.
- Once verified, select **PLAY MEGA MAN X5**.

The app remembers the selected file and automatically loads it on future launches.

### External Storage Setup
- Connect your external drive to the Xbox.
- Select **External Storage**. The file browser will open at `E:\`.
- Find and select your legally obtained Mega Man X5 USA `.BIN` file.
- Once verified, select **PLAY MEGA MAN X5**.

Keep the `.CUE` and `.BIN` files together if your disc image contains both. Save data and app settings are stored with the selected game on external storage when access is available.

### Additional Notes
- Press **Menu + View** together to open the settings menu during gameplay.
